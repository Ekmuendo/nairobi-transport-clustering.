# Nairobi Public Transport Clustering 🚍

This project analyzes and clusters public transport stops in Nairobi using GTFS data and machine learning.

## 📂 Files

- `transport_clustering.ipynb`: Main notebook with clustering logic and visualization.
- `gtfs.zip`: GTFS dataset used for stop locations.

## 📌 Key Features

- Clustering of transport stops using K-Means
- Interactive map showing clusters (powered by Folium)
- Optional: Nearest neighbor routing logic

## 🛠 Dependencies

- `pandas`
- `scikit-learn`
- `folium`
- `geopy` (optional for routing)

## 📊 How to Run

1. Unzip `gtfs.zip`
2. Open the notebook
3. Run all cells in order
